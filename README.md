# POS REPAIR SYSTEM

Enterprise-grade POS Repair & Inventory Workflow System.

## Purpose
This project is built step-by-step following professional software engineering practices:
- Business-first design
- Backend as source of truth
- Frontend as controlled consumer
- Full auditability and security

## Tech Stack (Planned)
- Frontend: HTML, CSS, JavaScript → React
- Backend: Node.js, NestJS
- Database: PostgreSQL
- Hosting: Vercel (Frontend), Cloud Backend
